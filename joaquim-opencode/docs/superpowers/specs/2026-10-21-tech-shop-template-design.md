# Template de site para loja de informática

## Intenção

Criar um template demonstrativo estático, hospedado no GitHub Pages, para que donos de lojas de informática visualizem um site profissional e adaptável ao próprio negócio. O modelo será listado no catálogo da agência e enviado aos clientes potenciais como prévia.

## Público

- **Primário:** dono de loja de informática que recebe o link da demonstração.
- **Secundário:** cliente final da loja, caso o dono aprove e personalize o modelo.

## Posicionamento

Uma loja de informática acolhedora e tecnicamente confiável. Não é uma loja virtual com carrinho: apresenta os serviços e convida o visitante a entrar em contato pelo WhatsApp para perguntar sobre peças, orçamentos e disponibilidade.

## Estrutura

- **Home**
  - Hero visual com identidade fictícia editável.
  - Serviços: conserto, upgrades/venda de peças, assistência geral.
  - Confiança: processo de atendimento, critérios verificáveis da loja real (marcas, garantia, orientação técnica).
  - CTA de contato da loja.
  - Footer.
  - Faixa discreta para personalização do modelo.
- **Saiba Mais**
  - História fictícia da loja.
  - Equipe/dono.
  - Localização e horário.

## Direção visual

Tech flat, sério e humano. Sem neon, gradientes, cards de ícone genéricos, depoimentos ou estatísticas inventadas. Visual principal baseado em uma bancada de informática ilustrada (notebook, peças, ferramentas), conectando conserto, upgrade e compra. Cores sólidas, com paleta editável via CSS variables.

## Stack

- HTML semântico estático.
- CSS puro com variáveis para fácil personalização.
- JavaScript mínimo para comportamentos leves.
- Hospedagem via GitHub Pages.

## Anti-objetivos

- Não ter catálogo de produtos com preços fixos.
- Não usar avaliações, números ou garantias fictícias.
- Não parecer loja de importados baratos ou promoção duvidosa.

## Decisões em aberto

- Nome e identidade visual fictícios da loja de demonstração.
- Número e mensagem do WhatsApp do modelo (placeholder).
- Paleta exata de cores (editável, mas precisa de valores padrão).
