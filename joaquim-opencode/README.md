# Setor Técnico — Site para loja de informática

Site estático, leve e direto para uma loja de informática e assistência técnica.

## Como usar

1. Abra `index.html` no navegador ou hospede em qualquer serviço estático (GitHub Pages, Netlify, Vercel, etc.).
2. Personalize os textos, telefone, endereço e e-mail diretamente nos arquivos.
3. Substitua a ilustração SVG em `.how-visual` por uma foto real da bancada, se preferir.

## O que está incluso

- Página única com navegação suave
- Seções: hero com ordem de serviço, serviços, peças, como funciona e contato
- Layout responsivo
- Paleta flat com acento azul-profundo e tipografia Archivo + IBM Plex Mono (Google Fonts)
- Nenhum depoimento falso, número inventado ou linguagem de marketing genérica

## Personalização rápida

- **Nome da loja:** substitua "Setor Técnico" e a sigla "ST" no `index.html`.
- **WhatsApp:** troque `5511999990000` pelo número correto em todos os links.
- **Endereço e mapa:** atualize o endereço na seção de contato e no `src` do iframe do Google Maps.
- **Cores:** edite as variáveis CSS no início de `css/style.css`.
